# Asset inventory

## Bundled artwork

| Files                                                   | Source                                                                                          | Terms                                   |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------- |
| `extension/background/1.svg` through `7.svg`            | Original procedural night landscapes generated by `scripts/generate-theme.cjs` for this project | MIT, with the project source            |
| `extension/spatial-audio.svg`                           | Original geometric icon generated by the same script                                            | MIT, with the project source            |
| SVG particle textures embedded in `extension/style.css` | Geometric rectangle/circle patterns already present in this project's CSS                       | Covered by the project's source license |

Run `npm run assets:generate` to regenerate the SVG files deterministically. They use gradients, geometric shapes, and procedural tree silhouettes; no downloaded photos, character portraits, third-party logos, or font files are bundled. Georgia and system fonts use the viewer's installed fonts.

The former background JPG/WebP files, `stranger.png`, and `dolby.webp` had no recorded sources. They were removed from the distributed source tree and replaced or removed. Do not reintroduce them without documenting their source and permission to redistribute.

## Documentation screenshots and references

Keep screenshots relevant to describing extension behavior and avoid personal account information.

## Adding assets

Record the file, creator, original source URL when applicable, license or permission terms, and required attribution here. Prefer assets you created for this project. If an asset's source is unknown, replace it instead of assigning it an assumed license.
